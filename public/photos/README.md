# Photo Placeholders

This folder holds real photo assets used in the portfolio.

## To activate the real photo

1. Drop your professional face photo here as `profile.jpg` (or `.webp`).
2. Recommended: 800x800px minimum, square crop, well-lit, neutral background.
3. The hero and about sections reference `/photos/profile.svg` — update them to `/photos/profile.jpg` after dropping the file.

Files:
- `profile.svg` — current placeholder (KF monogram, intentional design)
- `profile.jpg` — your real photo (you add this)
